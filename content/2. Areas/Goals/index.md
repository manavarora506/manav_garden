# 🧭 6-Month Software Engineer Interview Prep Timeline

**Target:** Start applying **January → February 2026** for summer roles

---

## **Phase 1 – Pattern Recognition Mastery**

**(Months 1-2: Oct → Nov 2025)**

### **Month 1 – October 2025: Pattern Recognition Speed**

**Week 1-2: Pattern Identification Focus**

- Keep solving daily random problems — but always start with a “pattern identification” step (5–10 min).
    
- Spot mixed patterns (e.g., two pointers + sliding window).
    
- Learn to link problem keywords → typical patterns.
    

**Week 3-4: Problem-to-Pattern Mapping**

- Build a decision tree: “If I see X → think Y.”
    
- Train on constraint-driven recognition (e.g., 10⁵ elements + O(1) space → two pointers).
    
- Practice fast pivots when your first instinct fails.
    
- Time pattern recognition (< 5 min goal).
    

---

### **Month 2 – November 2025: Advanced Recognition**

**Week 1-2**

- Multi-pattern problems (e.g., DFS + DP).
    
- Rank possible approaches by efficiency.
    
- Recognize and recover early from wrong paths.
    

**Week 3-4**

- “Rapid-fire” recognition drills (3 min limit).
    
- Explain why you chose each pattern aloud.
    
- Strengthen conviction in early intuition.
    
- Identify patterns with tricky edge cases.
    

---

## **Phase 2 – Skill Development**

**(Months 3-4: Dec 2025 → Jan 2026)**

### **Month 3 – December 2025: Core Algorithm Expansion**

**Week 1-2: Dynamic Programming (Fundamentals)**

- Master common DP sub-patterns (1D, 2D, memoization).
    
- Practice 4–6 problems/day (Easy–Medium).
    
- Key topics: Fibonacci, Coin Change, LCS, Knapsack.
    

**Week 3-4: Graph Algorithms**

- BFS/DFS variations, topological sort.
    
- Dijkstra vs Bellman-Ford.
    
- 1 graph problem/day min.
    
- Take advantage of Visa holiday downtime for long study blocks.
    

---

### **Month 4 – January 2026: System Design + Advanced Problem Solving**

**Week 1-2: System Design Intro**

- Read _Designing Data-Intensive Applications_.
    
- Review caching, load balancing, databases, queues.
    
- Watch Gaurav Sen / Tech Dummies videos.
    

**Week 3-4: Advanced Problem Solving**

- Medium–Hard LeetCode sets.
    
- Contest-style timed sessions.
    
- Learn advanced techniques: Union-Find, Sliding Window, Prefix Sum.
    
- Start light **mock interviews** (Pramp, Interviewing.io).
    
- **Begin applying late Jan → early Feb 2026** — target early-wave companies first.

## **Pattern Recognition Optimization**

### **Rapid-Fire Recognition Drill (Weekly)**

10 problems × 3 minutes each = pattern only.  
Log accuracy % + time to recognize.

### **Trigger Words & Constraints**

- “Contiguous subarray” → Sliding Window / Kadane’s
    
- “Count ways / all paths” → DP / DFS + memoization
    
- “Shortest path (unweighted)” → BFS
    
- “Large constraints (10⁹+)” → Binary Search / Math
    
- “O(1) space two results” → Two Pointers
    

### **Confidence Tracking**

Each month: record initial pattern guess vs final solution pattern.  
Goal = ≥ 85 % accuracy in < 5 min.

## **Weekly Study Structure**

**Weekdays (45-90 min)**

- Problem selection (5 min)
    
- Think-first (no coding) (15-20 min)
    
- Implement (25-30 min)
    
- Reflect (10-15 min)
    
- _1 problem/day for depth over breadth_
    

**Weekends (2-3 h/day)**

- Saturday: Pattern deconstruction (3-4 related problems).
    
- Sunday: Mock interviews & verbal explanations.
